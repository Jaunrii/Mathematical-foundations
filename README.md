# 数理基础自学讲义

当前建设主题为**概率论与随机过程**。这是面向自学的中文讲义网站，计划用 60 个学习日串联测度论、实分析、高等概率论、高维概率论与随机过程，每天约 2–3 小时。

## 本地运行

需要 Python 3（3.9 或更新版本）和 Node.js。KaTeX 已随仓库附带，无需另行安装 npm 包。

```sh
python3 build.py
python3 -m http.server --directory dist 8000
```

在浏览器打开 `http://localhost:8000`。停止预览时，在终端按 `Ctrl+C`。

## 目录

```text
content/             学习路线、诊断题、参考书目与教学方法记录
content/lessons/     正式讲义正文
content/lessons.json  正式讲义索引与章节考核
course-policy.json   章节要求与视频研究状态
build.py             将内容数据构建为浏览器可读取的文件
render-math.js       在构建时将公式转换为 MathML
vendor/katex/        KaTeX、版本记录与 MIT 许可证
dist/                可直接部署的静态网页与构建产物
```

修改 `content/` 中的数据后，重新运行 `python3 build.py`。构建程序会检查学习日编号、诊断题总分与正式讲义的发布前提。

公式在构建时转换为浏览器原生 MathML；阅读网页时无需加载在线公式渲染服务。若 Node.js 不在默认路径，可通过 `NODE_BINARY` 环境变量指定它的位置。

诊断和章节考核作答仅保存在访问者当前浏览器的本地存储中，不会自动上传到 GitHub，也不会自动获得批改。
