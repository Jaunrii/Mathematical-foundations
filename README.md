# 数理基础自学讲义

当前建设主题为**概率论与随机过程**。这是面向自学的中文讲义网站，计划用 60 个学习日串联测度论、实分析、高等概率论、高维概率论与随机过程，每天约 2–3 小时。

[访问讲义网站](https://probability-notebook-60.exactlime8.chatgpt.site/)

讲义将采用原创解释与练习，重点说明概念的动机、定理的用途与条件、证明的主线，以及知识之间的联系。

## 本地运行

只需 Python 3，无需安装第三方依赖。

```sh
python3 build.py
python3 -m http.server --directory dist 8000
```

在浏览器打开 `http://localhost:8000`。停止预览时，在终端按 `Ctrl+C`。

## 目录

```text
content/             学习路线、诊断题、参考书目与教学方法记录
course-policy.json   章节要求与正式讲义的发布前提
build.py             将内容数据构建为浏览器可读取的文件
dist/                可直接部署的静态网页与构建产物
```

修改 `content/` 中的数据后，重新运行 `python3 build.py`。构建程序会检查学习日编号、诊断题总分与正式讲义的发布前提。

诊断作答仅保存在访问者当前浏览器的本地存储中，不会自动上传到 GitHub，也不会自动获得批改。
